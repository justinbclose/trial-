What to do with it

  1. Copy it, then paste into a plain text editor. In TextEdit on a Mac choose Format → Make Plain Text first, or the file will not work.
  2. Save it as index.html — that exact name, not .txt.
  3. Keep it in a folder with your images folder beside it.
  4. Drag that folder onto app.netlify.com/drop to put it online free.

Your photographs

The Lifestyle chapter now carries a real photograph, loaded from images/lifestyle-beachside.jpg. Keep an images folder beside the HTML file and that path works as written.

Every other frame is still a placeholder. To fill one, replace its <span> — the one on a line containing class="ph, not the caption below it — with <img src="images/your-photo.jpg" alt="what it shows">.
